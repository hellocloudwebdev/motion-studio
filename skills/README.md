# Motion Studio skills

Skills are provider-neutral procedures loaded by specialist agents as needed. Each skill lives in its own directory and contains a `SKILL.md` with frontmatter metadata.

Current skills cover setup, end-to-end production, engine routing, HyperFrames + GSAP, After Effects, Premiere Pro, typography, QA/repair and governed skill evolution. Add reference files, examples and tests alongside the skill when a workflow becomes reusable. Version changes and evaluate them before promotion.
