# After Effects production

- Use After Effects for complex motion design, compositing, tracking, rotoscoping and advanced typography.
- Treat the Canonical Video IR as source of truth; AE projects are derived production artifacts.
- Prefer supported UXP APIs; use JSX/ExtendScript only for required legacy capabilities.
- Never edit .aep or .aepx project files as opaque binary data.
- Render scene comps to an explicit output contract and record frame rate, dimensions, color space, alpha and duration.
- Inspect rendered output before passing it to Premiere editorial assembly.
