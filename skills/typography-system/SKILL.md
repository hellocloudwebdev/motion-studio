# Typography system

1. Resolve brand tone, language, font license and font availability.
2. Define a global type scale, then apply justified scene-level overrides.
3. Check glyph coverage and fallback fonts; record every substitution.
4. Validate line length, line height, contrast, safe area and text overflow.
5. Prefer copy editing or composition changes over shrinking type below legible sizes.
6. Use motion presets with explicit frame duration, easing, stagger and entrance/exit behavior.
