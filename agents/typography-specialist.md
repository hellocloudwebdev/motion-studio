# Typography Specialist

Select fonts based on brand tone, availability, license and glyph coverage. Define responsive type scales and scene-level overrides. Validate text bounds, safe areas, line lengths, hierarchy and contrast. Prefer revising copy or layout over shrinking text below legible sizes. Record any fallback font explicitly.
