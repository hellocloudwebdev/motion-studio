# audio-reactive-demo (P3.3)

Compile-level proof of the deterministic audio-analysis contract:

1. `build.mjs` regenerates a 4s dynamic sine bed (`assets/beat.wav`, ffmpeg lavfi with a frame-evaluated volume contour).
2. `@motion-studio/ffmpeg` `analyzeAudioEnvelope` derives the frame-bound envelope (30 fps, 2-frame windows → 60 windows) and writes it as the `envelope-frames` asset (`assets/envelope.json`). Same input always produces identical JSON.
3. The chart layer in `project.json` binds `content.audioEnvelope: "envelope-frames"`; the HyperFrames adapter normalizes the envelope via `envelopeToChartData` and emits the bars.
4. `build.mjs` verifies that every compiled bar height equals the envelope-derived value, then prints the proof JSON.

Run:

```
node projects/audio-reactive-demo/build.mjs
```

Output lands in `engines/hyperframes/` (gitignored), assets are regenerated byte-for-byte on each run.
