# Software installation matrix

| Software | Role | Install automation | License |
|---|---|---|---|
| Node.js 22+ | Runtime | Bootstrap/package manager | Free |
| FFmpeg / FFprobe | Media pipeline | OS package manager | Open source |
| HyperFrames CLI | HTML/CSS scene rendering | npm | Open source |
| GSAP | Motion sequencing | npm workspace dependency | Check current license terms for commercial use |
| Three.js | WebGL scenes | npm workspace dependency | MIT |
| Blender | 3D scenes | OS package manager / official installer | GPL |
| After Effects | Advanced motion/VFX | Adobe Creative Cloud | Paid |
| Premiere Pro | Editorial assembly | Adobe Creative Cloud | Paid |
| Media Encoder | Adobe render queue | Adobe Creative Cloud | Included with eligible Adobe plans |
| Illustrator / Photoshop / Audition | Supporting creative tools | Adobe Creative Cloud | Paid |

A package being installed does not mean its engine adapter is implemented or production-ready. Run the doctor and verify each adapter independently.
